JavaScript API Usage

Create and control knobs programmatically with full access to the JavaScript API. Best for dynamic applications and complex interactions.

Creating Controls

Knob
Slider

Basic Usage

// ES Module import import { Knob, Slider } from 'audio-knobs'; // Create a knob const knob = new Knob('#my-knob', { min: 0, max: 100, value: 50, label: 'Volume' }); // Create a slider const slider = new Slider('#my-slider', { min: 0, max: 10, value: 5, label: 'Level' });

Event Handling

Responding to Changes

Value: 50
const knob = new Knob('#knob', { min: 0, max: 100, value: 50 }); // Listen for changes knob.onChange(function(event) { console.log('Value:', event.value); console.log('Previous:', event.previousValue); console.log('Angle:', event.angle); }); // Remove listener knob.off('change', myCallback);

Programmatic Control

Getting & Setting Values

Current: 50
// Get current value const value = knob.getValue(); // Set value programmatically knob.setValue(75); // Get the DOM element const element = knob.getElement(); // Clean up when done knob.destroy();

Pre-configured Controls

<!DOCTYPE html> <html> <head> <title>Audio Mixer</title> <style> .mixer { display: flex; gap: 20px; padding: 30px; background: #222; } .channel { text-align: center; } </style> </head> <body> <div class="mixer"> <div class="channel" id="ch1"></div> <div class="channel" id="ch2"></div> <div class="channel" id="master"></div> </div> <script type="module"> import { Slider } from 'https://unpkg.com/audio-knobs/dist/knobs.esm.js'; // Create mixer channels const ch1 = new Slider('#ch1', { min: 0, max: 10, value: 7, length: 150, label: 'CH 1' }); const ch2 = new Slider('#ch2', { min: 0, max: 10, value: 5, length: 150, label: 'CH 2' }); const master = new Slider('#master', { min: 0, max: 10, value: 8, length: 150, label: 'Master', thumbColor: '#cc4444' }); // Handle changes ch1.onChange(e => console.log('CH1:', e.value)); ch2.onChange(e => console.log('CH2:', e.value)); master.onChange(e => console.log('Master:', e.value)); </script> </body> </html>
