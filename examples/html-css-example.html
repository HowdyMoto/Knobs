HTML & CSS Example

Declarative HTML Usage

Create knobs and sliders using HTML classes and data attributes. No JavaScript configuration needed - just call initFromDOM() once.

Basic Knobs

Volume
Pan
Frequency

HTML

<!-- Include the library --> <script src="audio-knobs/dist/knobs.js"></script> <!-- Create knobs with data attributes --> <div class="audio-knob" data-min="0" data-max="10" data-value="5" data-label="Volume"> </div> <div class="audio-knob" data-min="0" data-max="100" data-value="50" data-label="Pan"> </div> <div class="audio-knob" data-min="20" data-max="20000" data-value="1000" data-label="Freq"> </div> <!-- Initialize all knobs --> <script> Knobs.initFromDOM(); </script>

Custom Styled Knobs

HTML with Styling Attributes

<!-- Vintage style --> <div class="audio-knob" data-min="0" data-max="11" data-value="7" data-size="70" data-dial-color="#8b4513" data-indicator-color="#f5deb3" data-tick-color="#daa520" data-tick-count="12"> </div> <!-- Modern style with value display --> <div class="audio-knob" data-min="0" data-max="100" data-value="75" data-dial-color="#1a1a1a" data-indicator-color="#00ff88" data-show-value-display="true"> </div> <!-- Minimal style (no ticks) --> <div class="audio-knob" data-dial-color="#e74c3c" data-indicator-color="#fff" data-show-ticks="false"> </div>

Sliders

HTML

<!-- Basic slider --> <div class="audio-slider" data-min="0" data-max="10" data-value="7" data-length="140" data-label="Vol"> </div> <!-- Slider with value display --> <div class="audio-slider" data-min="-24" data-max="12" data-value="0" data-label="Gain" data-show-value-display="true" data-thumb-color="#ff6b6b"> </div> <!-- Custom colored slider --> <div class="audio-slider" data-thumb-color="#4ecdc4" data-track-color="#1a1a1a"> </div>

Complete HTML File

Full Working Example

<!DOCTYPE html> <html> <head> <title>My Audio App</title> <style> .controls { display: flex; gap: 20px; padding: 20px; background: #222; } </style> </head> <body> <div class="controls"> <div class="audio-knob" data-min="0" data-max="100" data-value="50" data-label="Volume"> </div> <div class="audio-slider" data-min="0" data-max="10" data-value="5" data-label="Fader"> </div> </div> <!-- Include library (IIFE build for script tags) --> <script src="https://unpkg.com/audio-knobs/dist/knobs.js"></script> <script> // Initialize all controls from HTML const { knobs, sliders } = Knobs.initFromDOM(); // Optionally add event listeners knobs[0].onChange(function(e) { console.log('Volume:', e.value); }); </script> </body> </html>

Available Data Attributes

Knob Attributes

data-min // Minimum value (default: 0) data-max // Maximum value (default: 10) data-value // Initial value (default: 5) data-step // Step increment (default: 0.1) data-size // Diameter in pixels (default: 60) data-label // Label text below knob data-mode // 'bounded' or 'infinite' data-dial-color // Dial face color data-indicator-color // Pointer/indicator color data-tick-color // Tick mark color data-label-color // Label text color data-tick-count // Number of tick marks data-show-ticks // Show tick marks (true/false) data-show-value-display // Show numeric readout

Slider Attributes

data-min // Minimum value (default: 0) data-max // Maximum value (default: 10) data-value // Initial value (default: 5) data-step // Step increment (default: 0.1) data-length // Track length in pixels data-width // Track width in pixels data-label // Label text below slider data-thumb-color // Thumb/handle color data-track-color // Track background color data-show-value-display // Show numeric readout data-show-toggle // Show mute toggle button data-toggle-label // Toggle button label
