Creating Controls

Create knobs and sliders with minimal configuration. Just specify a container and optional settings.

import { Knob, Slider } from 'audio-knobs'; // Create a knob const knob = new Knob('#my-knob', { min: 0, max: 100, value: 50 }); // Create a slider const slider = new Slider('#my-slider', { min: 0, max: 10, value: 5 });

Bounded vs Endless

Bounded knobs have hard stops at min/max values. Endless knobs rotate continuously (like encoders) and wrap around.

// Bounded (has min/max stops) new Knob('#bounded', { mode: 'bounded', min: 0, max: 11 }); // Endless (wraps around) new Knob('#endless', { mode: 'endless', min: 0, max: 100 });

Event Handling

Events

Responding to Changes

Use the onChange callback to respond to user input. The callback receives the current value.

Value: 50
const knob = new Knob('#knob', { value: 50 }); knob.onChange((event) => { console.log('Value:', event.value); console.log('Normalized:', event.normalizedValue); });

Customize every visual aspect including colors, sizes, and tick marks.

new Knob('#knob', { size: 70, dialColor: '#8b4513', bezelColor: '#5a3510', indicatorColor: '#f5deb3', tickColor: '#daa520', labelColor: '#f5deb3', tickCount: 11, showTicks: true });

Pre-configured Controls

Use factory functions for common control types with sensible defaults.

import { createPanKnob, createMuteFader } from 'audio-knobs'; // Pan knob: -100 (L) to +100 (R), centered at 0 const pan = createPanKnob('#pan', { label: 'Pan' }); // Mute fader: slider with mute toggle button const fader = createMuteFader('#fader', { label: 'Volume', toggleLabel: 'Mute' });

Create Controls with HTML Classes

Define knobs and sliders directly in HTML using classes and data attributes. Call initFromDOM() to initialize them all at once.

<!-- HTML: Just add classes and data attributes --> <div class="audio-knob" data-min="0" data-max="10" data-value="7" data-label="Volume"></div> <div class="audio-slider" data-min="0" data-max="100" data-value="50" data-label="Fader"></div>
// JavaScript: Initialize all controls in one call import { initFromDOM } from 'audio-knobs'; const { knobs, sliders } = initFromDOM(); // Access initialized controls knobs[0].onChange((e) => { console.log('Volume:', e.value); });

Available Data Attributes

All knob and slider options can be set via data attributes using kebab-case naming.

<!-- Common attributes --> data-min // Minimum value data-max // Maximum value data-value // Initial value data-step // Step increment data-label // Label text <!-- Knob-specific --> data-size // Diameter in pixels data-mode // 'bounded' or 'endless' data-dial-color // Dial face color data-indicator-color // Pointer color <!-- Slider-specific --> data-length // Track length in pixels data-thumb-color // Thumb/handle color data-track-color // Track background color <!-- Display options --> data-show-ticks // Show tick marks (true/false) data-show-value-display // Show numeric value data-tick-count // Number of tick marks
